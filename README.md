# RLGB radio tracking dashboard

Public dashboard for the Ruel Living Gene Bank (RLGB) adult salmon radio-tracking study (Argyll Fisheries Trust).
This repository holds only the Shiny app (`app.R`), the processed data it reads (`data/rlgb.rds`) and the package list
(`manifest.json`). It is rebuilt once a day from the study's decoded receiver data and republished on Posit Connect Cloud.
